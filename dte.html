Subtracting, Negative Numbers, and Making \(x\) the Subject

These notes are written in short, clear steps. Read one step at a time, and pause whenever you need. If a line feels difficult, cover the rest and focus on just that line.

Jump to Practice Questions

1) Subtracting is Adding a Negative

You can think of subtraction as adding a negative number.

\[5 - 2 = 3\]

The same idea can be written as:

\[5 + (-2) = 3\]

A negative number can also be written as a positive number multiplied by \(-1\):

\[-2 = 2 \times (-1)\]

So another equivalent form is:

\[5 + (2 \times -1) = 3\]

Key idea: subtracting a number and adding its negative give the same result.

2) Add or Subtract the Same Thing on Both Sides

To keep an equation balanced, whatever you do to the left side, do the same to the right side.

Your goal is to get \(x\) on its own.

Example 1

\[y = x + 5\]

Left side: \(y\)
Right side: \(x + 5\)
Operation: subtract 5 from both sides.
Left side: \(y - 5\)
Right side: \(x + 5 - 5 = x + 0 = x\)
Write the equation with the new left and right side.

\[y - 5 = x\]

Since \(x\) is now the subject, this is the answer.

Example 2

\[y = x + 3 + c\]

Left side: \(y\)
Right side: \(x + 3 + c\)
Operation: subtract 3 from both sides.
Left side: \(y - 3\)
Right side: \(x + 3 + c - 3 = x + c + 0 = x + c\)
Write the equation with the new left and right side.

\[y - 3 = x + c\]

Left side: \(y - 3\)
Right side: \(x + c\)
Operation: subtract \(c\) from both sides.
Left side: \(y - 3 - c\)
Right side: \(x + c - c = x + 0 = x\)
Write the equation with the new left and right side.

\[y - 3 - c = x\]

Since \(x\) is now the subject, this is the answer.

Example 3

\[y = x - 12 + c\]

Left side: \(y\)
Right side: \(x - 12 + c\)
Operation: add 12 to both sides.
Left side: \(y + 12\)
Right side: \(x - 12 + c + 12 = x + c + 0 = x + c\)
Write the equation with the new left and right side.

\[y + 12 = x + c\]

Left side: \(y + 12\)
Right side: \(x + c\)
Operation: subtract \(c\) from both sides.
Left side: \(y + 12 - c\)
Right side: \(x + c - c = x + 0 = x\)
Write the equation with the new left and right side.

\[y + 12 - c = x\]

Since \(x\) is now the subject, this is the answer.

Example 4

\[y = x - \frac{c}{4}\]

Left side: \(y\)
Right side: \(x - \frac{c}{4}\)
Operation: add \(\frac{c}{4}\) to both sides.
Left side: \(y + \frac{c}{4}\)
Right side: \(x - \frac{c}{4} + \frac{c}{4} = x + 0 = x\)
Write the equation with the new left and right side.

\[y + \frac{c}{4} = x\]

Since \(x\) is now the subject, this is the answer.

Example 5

\[y = x + 2d^2\]

Left side: \(y\)
Right side: \(x + 2d^2\)
Operation: subtract \(2d^2\) from both sides.
Left side: \(y - 2d^2\)
Right side: \(x + 2d^2 - 2d^2 = x + 0 = x\)
Write the equation with the new left and right side.

\[y - 2d^2 = x\]

Since \(x\) is now the subject, this is the answer.

Question 8 (More Difficult)

Make \(x\) the subject:

\[y = x - \frac{3c}{5} + 2d\]

Right side: \(x - \frac{3c}{5} + 2d\)

Left side: \(y + \frac{3c}{5}\)

Right side: \(x + 2d\)

Left side: \(y + \frac{3c}{5} - 2d\)
Right side: \(x + 2d - 2d = x\)

\[y + \frac{3c}{5} - 2d = x\]

Since \(x\) is now the subject, the answer is \(x = y + \frac{3c}{5} - 2d\).

Question 9 (More Difficult)

Make \(x\) the subject:

\[y = x + \frac{a}{3} - \frac{b}{4} + 7\]

Left side: \(y\)
Right side: \(x + \frac{a}{3} - \frac{b}{4} + 7\)
Operation: subtract 7 from both sides.
Left side: \(y - 7\)
Right side: \(x + \frac{a}{3} - \frac{b}{4}\)

\[y - 7 = x + \frac{a}{3} - \frac{b}{4}\]

Operation: subtract \(\frac{a}{3}\) from both sides.
Left side: \(y - 7 - \frac{a}{3}\)
Right side: \(x + \frac{a}{3} - \frac{b}{4} - \frac{a}{3} = x - \frac{b}{4}\)

\[y - 7 - \frac{a}{3} = x - \frac{b}{4}\]

Operation: add \(\frac{b}{4}\) to both sides.
Left side: \(y - 7 - \frac{a}{3} + \frac{b}{4}\)
Right side: \(x - \frac{b}{4} + \frac{b}{4} = x\)

\[y - 7 - \frac{a}{3} + \frac{b}{4} = x\]

Since \(x\) is now the subject, the answer is \(x = y - 7 - \frac{a}{3} + \frac{b}{4}\).

4) Multiply or Divide the Same Thing on Both Sides

Sometimes you need to multiply or divide both sides of an equation to get \(x\) on its own.

Remember: when you multiply or divide, do it to the entire side using brackets, then simplify.

Example 1

\[y = \frac{3x}{2} + 4\]

Left side: \(y\)
Right side: \(\frac{3x}{2} + 4\)
Operation: subtract 4 from both sides.
Left side: \(y - 4\)
Right side: \(\frac{3x}{2} + 4 - 4 = \frac{3x}{2}\)

\[y - 4 = \frac{3x}{2}\]

Operation: multiply both sides by 2. Use brackets to keep everything clear.
Left side: \(2(y - 4) = 2y - 8\)
Right side: \(2 \times \frac{3x}{2} = \frac{2 \times 3x}{2} = \frac{6x}{2} = 3x\)

\[2y - 8 = 3x\]

Operation: divide both sides by 3.
Left side: \(\frac{2y - 8}{3}\)
Right side: \(\frac{3x}{3} = x\)

\[\frac{2y - 8}{3} = x\]

Since \(x\) is now the subject, this is the answer.

Example 2

\[y = 2x + 5\]

Left side: \(y\)
Right side: \(2x + 5\)
Operation: subtract 5 from both sides.
Left side: \(y - 5\)
Right side: \(2x\)

\[y - 5 = 2x\]

Operation: divide both sides by 2.
Left side: \(\frac{y - 5}{2}\)
Right side: \(\frac{2x}{2} = x\)

\[\frac{y - 5}{2} = x\]

Since \(x\) is now the subject, this is the answer.

Example 3

\[y = \frac{x}{4} - 3\]

Left side: \(y\)
Right side: \(\frac{x}{4} - 3\)
Operation: add 3 to both sides.
Left side: \(y + 3\)
Right side: \(\frac{x}{4}\)

\[y + 3 = \frac{x}{4}\]

Operation: multiply both sides by 4.
Left side: \(4(y + 3) = 4y + 12\)
Right side: \(4 \times \frac{x}{4} = x\)

\[4y + 12 = x\]

Since \(x\) is now the subject, this is the answer.

Example 4

\[y = \frac{2x + 6}{5}\]

Left side: \(y\)
Right side: \(\frac{2x + 6}{5}\)
Operation: multiply both sides by 5.
Left side: \(5y\)
Right side: \(5 \times \frac{2x + 6}{5} = 2x + 6\)

\[5y = 2x + 6\]

Operation: subtract 6 from both sides.
Left side: \(5y - 6\)
Right side: \(2x\)

\[5y - 6 = 2x\]

Operation: divide both sides by 2.
Left side: \(\frac{5y - 6}{2}\)
Right side: \(x\)

\[\frac{5y - 6}{2} = x\]

Since \(x\) is now the subject, this is the answer.
