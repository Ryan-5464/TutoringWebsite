1) Key Trigonometric Values

You need to know the exact values of \(\sin\), \(\cos\) and \(\tan\) for certain angles. These appear frequently in exam questions and allow you to give exact answers rather than decimals.

Angles on the unit circle: 0°, 90°, 180°, 270°, 360°

\(x\) \(0°\) \(90°\) \(180°\) \(270°\) \(360°\)
\(\sin x\) \(0\) \(1\) \(0\) \(-1\) \(0\)
\(\cos x\) \(1\) \(0\) \(-1\) \(0\) \(1\)
\(\tan x\) \(0\) undefined \(0\) undefined \(0\)
\(\tan x\) is undefined at 90° and 270° because \(\tan x = \frac{\sin x}{\cos x}\) and \(\cos 90° = \cos 270° = 0\), which would mean dividing by zero.

Special angles: 30°, 45°, 60°

These three angles come from two standard triangles (the 30-60-90 and the 45-45-90 triangle). Their exact values involve surds.

\(x\) \(30°\) \(45°\) \(60°\)
\(\sin x\) \(\dfrac{1}{2}\) \(\dfrac{\sqrt{2}}{2}\) \(\dfrac{\sqrt{3}}{2}\)
\(\cos x\) \(\dfrac{\sqrt{3}}{2}\) \(\dfrac{\sqrt{2}}{2}\) \(\dfrac{1}{2}\)
\(\tan x\) \(\dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}\) \(1\) \(\sqrt{3}\)
Memory tip: for \(\sin\), the pattern across 30°, 45°, 60° is \(\frac{1}{2},\ \frac{\sqrt{2}}{2},\ \frac{\sqrt{3}}{2}\) — numerators are \(\sqrt{1}, \sqrt{2}, \sqrt{3}\). For \(\cos\) the pattern is exactly reversed.

2) The CAST Diagram — Which Quadrant to Use

When you solve a trig equation like \(\sin x = -\tfrac{1}{2}\), your calculator gives you one answer (the reference angle), but there are usually two angles between 0° and 360° that work. The CAST diagram tells you which quadrants to use.

What CAST stands for

Each letter tells you which trig function is positive in that quadrant. Everything else is negative in that quadrant.

S
Q2 — 90° to 180°
Sin +
Cos −, Tan −
A
Q1 — 0° to 90°
All + (Sin, Cos, Tan)
T
Q3 — 180° to 270°
Tan +
Sin −, Cos −
C
Q4 — 270° to 360°
Cos +
Sin −, Tan −
How to read it: If you need \(\sin x\) to be negative, look for the quadrants where Sin is not listed as positive — that's Q3 and Q4.

The four quadrant formulas

Once you know which quadrants to use, these formulas convert the reference angle \(\theta\) into the actual angle \(x\):

Quadrant 1 (0°–90°)
\(x = \theta\)
The angle is just the reference angle itself.
Quadrant 2 (90°–180°)
\(x = 180° - \theta\)
Subtract the reference angle from 180°.
Quadrant 3 (180°–270°)
\(x = 180° + \theta\)
Add the reference angle to 180°.
Quadrant 4 (270°–360°)
\(x = 360° - \theta\)
Subtract the reference angle from 360°.

Step-by-step method

  1. Rearrange the equation so the trig function is on its own (e.g. \(\sin x = -\tfrac{1}{2}\)).
  2. Find the reference angle \(\theta\): ignore the sign for now and use the positive value. Look it up in the key values table, or use \(\sin^{-1}\), \(\cos^{-1}\), or \(\tan^{-1}\) on your calculator.
  3. Decide the sign of your answer (positive or negative).
  4. Use the CAST diagram to find which two quadrants give that sign.
  5. Apply the quadrant formulas above to write both angles.

Worked walk-through — Solve \(\sin x = -\dfrac{1}{2}\) for \(0° \leq x \leq 360°\)

Step 1: The trig function is already isolated. We need \(\sin x = -\dfrac{1}{2}\).
Step 2: Find the reference angle using the positive value. \(\sin \theta = \dfrac{1}{2} \Rightarrow \theta = 30°\)
Step 3: The answer is negative. In which quadrants is Sin negative? From the CAST diagram: Q3 and Q4.
Step 4: Apply the Q3 formula: \(x = 180° + 30° = 210°\)
Step 5: Apply the Q4 formula: \(x = 360° - 30° = 330°\)

\[\boxed{x = 210° \text{ or } x = 330°}\]

Quick check: \(\sin 210° = -\tfrac{1}{2}\) ✓   \(\sin 330° = -\tfrac{1}{2}\) ✓

Quick reference: which quadrants for each sign?

Sin positive → Q1 and Q2   |   Sin negative → Q3 and Q4

Cos positive → Q1 and Q4   |   Cos negative → Q2 and Q3

Tan positive → Q1 and Q3   |   Tan negative → Q2 and Q4

3) More Worked Examples — Solving Trig Equations

These examples all follow the same five-step method from Section 2. Each one shows a different function and a different sign combination.

Example 1 — Solve \(\cos x = -\dfrac{\sqrt{3}}{2}\) for \(0° \leq x \leq 360°\)

Reference angle: \(\cos \theta = \dfrac{\sqrt{3}}{2} \Rightarrow \theta = 30°\)
The answer is negative. Cos is negative in Q2 and Q3.
Q2 formula: \(x = 180° - 30° = 150°\)
Q3 formula: \(x = 180° + 30° = 210°\)

\[\boxed{x = 150° \text{ or } x = 210°}\]

Example 2 — Solve \(\tan x = 1\) for \(0° \leq x \leq 360°\)

Reference angle: \(\tan \theta = 1 \Rightarrow \theta = 45°\)
The answer is positive. Tan is positive in Q1 and Q3.
Q1 formula: \(x = 45°\)
Q3 formula: \(x = 180° + 45° = 225°\)

\[\boxed{x = 45° \text{ or } x = 225°}\]

Example 3 — Solve \(2\cos x + \sqrt{2} = 0\) for \(0° \leq x \leq 360°\)

Rearrange first: \(2\cos x = -\sqrt{2} \Rightarrow \cos x = -\dfrac{\sqrt{2}}{2}\)
Reference angle: \(\cos \theta = \dfrac{\sqrt{2}}{2} \Rightarrow \theta = 45°\)
The answer is negative. Cos is negative in Q2 and Q3.
Q2 formula: \(x = 180° - 45° = 135°\)
Q3 formula: \(x = 180° + 45° = 225°\)

\[\boxed{x = 135° \text{ or } x = 225°}\]

Example 4 — Solve \(\sin x = \dfrac{\sqrt{3}}{2}\) for \(0° \leq x \leq 360°\)

Reference angle: \(\sin \theta = \dfrac{\sqrt{3}}{2} \Rightarrow \theta = 60°\)
The answer is positive. Sin is positive in Q1 and Q2.
Q1 formula: \(x = 60°\)
Q2 formula: \(x = 180° - 60° = 120°\)

\[\boxed{x = 60° \text{ or } x = 120°}\]

Example 5 — Solve \(\tan x = -\dfrac{1}{\sqrt{3}}\) for \(0° \leq x \leq 360°\)

Reference angle: \(\tan \theta = \dfrac{1}{\sqrt{3}} \Rightarrow \theta = 30°\)
The answer is negative. Tan is negative in Q2 and Q4.
Q2 formula: \(x = 180° - 30° = 150°\)
Q4 formula: \(x = 360° - 30° = 330°\)

\[\boxed{x = 150° \text{ or } x = 330°}\]

Question 1

Solve \(\sin x = -1\) for \(0° \leq x \leq 360°\).

Reference angle: \(\sin \theta = 1 \Rightarrow \theta = 90°\).
\(\sin x\) is negative → Quadrants 3 and 4.
Q3: \(x = 180° + 90° = 270°\)    Q4: \(x = 360° - 90° = 360°\equiv 0°\)

\[\boxed{x = 270°}\]

Solve \(2\cos x = 1\) for \(0° \leq x \leq 360°\).

Rearrange: \(\cos x = \dfrac{1}{2}\).
Reference angle: \(\cos \theta = \dfrac{1}{2} \Rightarrow \theta = 60°\).
\(\cos x\) is positive → Quadrants 1 and 4.
Q1: \(x = 60°\)    Q4: \(x = 360° - 60° = 300°\)

\[\boxed{x = 60° \text{ or } x = 300°}\]

Question 3

Solve \(\tan x = -\sqrt{3}\) for \(0° \leq x \leq 360°\).

Reference angle: \(\tan \theta = \sqrt{3} \Rightarrow \theta = 60°\).
\(\tan x\) is negative → Quadrants 2 and 4.
Q2: \(x = 180° - 60° = 120°\)    Q4: \(x = 360° - 60° = 300°\)

\[\boxed{x = 120° \text{ or } x = 300°}\]

Question 4

Solve \(2\sin x + \sqrt{2} = 0\) for \(0° \leq x \leq 360°\).

Rearrange: \(\sin x = -\dfrac{\sqrt{2}}{2}\).
Reference angle: \(\sin \theta = \dfrac{\sqrt{2}}{2} \Rightarrow \theta = 45°\).
\(\sin x\) is negative → Quadrants 3 and 4.
Q3: \(x = 180° + 45° = 225°\)    Q4: \(x = 360° - 45° = 315°\)

\[\boxed{x = 225° \text{ or } x = 315°}\]

Question 5

Write down the exact value of \(\sin 150°\) and \(\cos 240°\).

\(\sin 150° = \sin(180° - 30°) = \sin 30° = \dfrac{1}{2}\)
\(\cos 240° = \cos(180° + 60°) = -\cos 60° = -\dfrac{1}{2}\)

\[\boxed{\sin 150° = \tfrac{1}{2}, \quad \cos 240° = -\tfrac{1}{2}}\]

5) Straight Lines and Circles

5a) Equation of a Straight Line

The general form of a straight line is:

\[y = mx + c\]

where \(m\) is the gradient (steepness) and \(c\) is the \(y\)-intercept (where the line crosses the \(y\)-axis).

Gradient formula given two points \((x_1, y_1)\) and \((x_2, y_2)\):

\[m = \frac{y_2 - y_1}{x_2 - x_1}\]

Example — Find the equation of the line through \((1, 3)\) and \((4, 9)\)

Find the gradient: \(m = \dfrac{9 - 3}{4 - 1} = \dfrac{6}{3} = 2\)
Use \(y = mx + c\) with one point, say \((1, 3)\): \[3 = 2(1) + c \Rightarrow c = 1\]

\[\boxed{y = 2x + 1}\]

5b) Equation of a Circle

A circle with centre at the origin \((0, 0)\) and radius \(r\) has the equation:

\[x^2 + y^2 = r^2\]

Example — Write down the equation of the circle with centre the origin and radius \(5\)

Substitute \(r = 5\) into \(x^2 + y^2 = r^2\).

\[\boxed{x^2 + y^2 = 25}\]

5c) Perpendicular Lines

Two lines are perpendicular when the product of their gradients equals \(-1\):

\[m_1 \times m_2 = -1 \quad \Longleftrightarrow \quad m_2 = -\frac{1}{m_1}\]

To find the equation of a perpendicular line through a given point:

  1. Find the gradient of the original line.
  2. Take the negative reciprocal to get the perpendicular gradient.
  3. Substitute the point and new gradient into \(y = mx + c\).

Example — Find the equation of the perpendicular to \(y = 3x - 5\) through \((6, 4)\)

Gradient of original line: \(m_1 = 3\).
Perpendicular gradient: \(m_2 = -\dfrac{1}{3}\).
Use \(y = m_2 x + c\) with point \((6, 4)\): \[4 = -\tfrac{1}{3}(6) + c \Rightarrow 4 = -2 + c \Rightarrow c = 6\]

\[\boxed{y = -\frac{1}{3}x + 6}\]

5d) Points of Intersection

To find where two lines (or a line and a circle) intersect, set their equations equal and solve simultaneously.

Example — Find where \(y = 2x + 1\) and \(y = -x + 7\) intersect

Set equal: \(2x + 1 = -x + 7\)
Solve: \(3x = 6 \Rightarrow x = 2\)
Substitute back: \(y = 2(2) + 1 = 5\)

\[\boxed{(2,\ 5)}\]

Example — Find where the line \(y = x + 1\) intersects the circle \(x^2 + y^2 = 25\)

Substitute \(y = x + 1\) into \(x^2 + y^2 = 25\): \[x^2 + (x+1)^2 = 25\]
Expand: \(x^2 + x^2 + 2x + 1 = 25\)
Simplify: \(2x^2 + 2x - 24 = 0 \Rightarrow x^2 + x - 12 = 0\)
Factorise: \((x + 4)(x - 3) = 0 \Rightarrow x = -4 \text{ or } x = 3\)
Find \(y\) values: \(x = -4 \Rightarrow y = -3\); \(x = 3 \Rightarrow y = 4\)

\[\boxed{(-4,\ -3) \text{ and } (3,\ 4)}\]

Question 1

Find the equation of the straight line through \((2, 5)\) and \((6, 13)\).

Gradient: \(m = \dfrac{13 - 5}{6 - 2} = \dfrac{8}{4} = 2\)
Using \((2, 5)\): \(5 = 2(2) + c \Rightarrow c = 1\)

\[\boxed{y = 2x + 1}\]

Question 2

Find the equation of the line perpendicular to \(y = \dfrac{1}{2}x + 3\) passing through \((4, 1)\).

Gradient of original line: \(m_1 = \dfrac{1}{2}\).
Perpendicular gradient: \(m_2 = -2\).
Using \((4, 1)\): \(1 = -2(4) + c \Rightarrow c = 9\)

\[\boxed{y = -2x + 9}\]

Question 3

Find the coordinates of the intersection of \(y = 3x - 2\) and \(y = -2x + 8\).

Set equal: \(3x - 2 = -2x + 8\)
Solve: \(5x = 10 \Rightarrow x = 2\)
Substitute: \(y = 3(2) - 2 = 4\)

\[\boxed{(2,\ 4)}\]

Question 4

Find where the line \(y = 2x - 3\) intersects the circle \(x^2 + y^2 = 20\).

Substitute \(y = 2x - 3\) into \(x^2 + y^2 = 20\): \[x^2 + (2x-3)^2 = 20\]
Expand: \(x^2 + 4x^2 - 12x + 9 = 20\)
Simplify: \(5x^2 - 12x - 11 = 0\)
Use the quadratic formula: \(x = \dfrac{12 \pm \sqrt{144 + 220}}{10} = \dfrac{12 \pm \sqrt{364}}{10}\)
\(\sqrt{364} = 2\sqrt{91}\), so \(x = \dfrac{12 \pm 2\sqrt{91}}{10} = \dfrac{6 \pm \sqrt{91}}{5}\)
For each \(x\), find \(y = 2x - 3\).

\[\boxed{x = \frac{6 + \sqrt{91}}{5},\quad x = \frac{6 - \sqrt{91}}{5}}\]

Approximately \(x \approx 3.11\) or \(x \approx -0.71\).

Question 5 (More Difficult)

The line \(L\) passes through \((0, 5)\) and is perpendicular to the line joining \(A(1, 3)\) and \(B(5, 1)\). Find the equation of \(L\) and the coordinates where \(L\) crosses the \(x\)-axis.

Gradient of \(AB\): \(m_{AB} = \dfrac{1 - 3}{5 - 1} = \dfrac{-2}{4} = -\dfrac{1}{2}\)
Perpendicular gradient: \(m_L = 2\)
Line \(L\) passes through \((0, 5)\), so \(c = 5\): \(\quad y = 2x + 5\)
Set \(y = 0\) to find the \(x\)-intercept: \(0 = 2x + 5 \Rightarrow x = -\dfrac{5}{2}\)

\[\boxed{y = 2x + 5;\quad \text{crosses } x\text{-axis at } \left(-\tfrac{5}{2},\ 0\right)}\]

7) Composite and Inverse Functions

7a) Composite Functions

A composite function means applying one function and then feeding the result straight into another. The notation \(fg(x)\) means apply \(g\) first, then apply \(f\) to the result:

\[fg(x) = f\bigl(g(x)\bigr)\]

Order matters: \(fg(x)\) and \(gf(x)\) are usually different. Read right-to-left — the function closest to \(x\) is applied first.

Example 1 — Find \(fg(x)\) and \(gf(x)\)

Let \(f(x) = 2x + 1\) and \(g(x) = x^2\).

\(fg(x)\): apply \(g\) first, then \(f\).
\(fg(x) = f\bigl(g(x)\bigr) = f(x^2) = 2x^2 + 1\)
\(gf(x)\): apply \(f\) first, then \(g\).
\(gf(x) = g\bigl(f(x)\bigr) = g(2x+1) = (2x+1)^2\)

\[\boxed{fg(x) = 2x^2 + 1, \qquad gf(x) = (2x+1)^2}\]

Example 2 — Evaluate a composite function numerically

Let \(f(x) = x + 5\) and \(g(x) = 2x\). Find \(fg(3)\).

Work from the inside out. First find \(g(3)\): \[g(3) = 2 \times 3 = 6\]
Now apply \(f\) to that result: \[f(6) = 6 + 5 = 11\]

\[\boxed{fg(3) = 11}\]

Example 3 — Expand and simplify a composite function

Let \(f(x) = 3x - 2\) and \(g(x) = x + 4\). Find \(gf(x)\) in simplified form.

Apply \(f\) first: \(f(x) = 3x - 2\)
Apply \(g\) to the result: \(g(3x-2) = (3x-2) + 4 = 3x + 2\)

\[\boxed{gf(x) = 3x + 2}\]

7b) Inverse Functions

The inverse function \(f^{-1}(x)\) undoes \(f\). If \(f\) maps \(a\) to \(b\), then \(f^{-1}\) maps \(b\) back to \(a\).

Method to find \(f^{-1}(x)\):

  1. Write \(y = f(x)\).
  2. Rearrange to make \(x\) the subject.
  3. Replace every \(y\) with \(x\) in your answer — that expression is \(f^{-1}(x)\).
Check: \(f\bigl(f^{-1}(x)\bigr) = x\) always. Substituting your answer back into \(f\) should give you \(x\) if it is correct.

Example 4 — Find the inverse of \(f(x) = 3x - 2\)

Write \(y = 3x - 2\).
Rearrange for \(x\): \(y + 2 = 3x \Rightarrow x = \dfrac{y+2}{3}\)
Replace \(y\) with \(x\):

\[\boxed{f^{-1}(x) = \frac{x+2}{3}}\]

Check: \(f\!\left(\dfrac{x+2}{3}\right) = 3 \cdot \dfrac{x+2}{3} - 2 = x + 2 - 2 = x\) ✓

Example 5 — Find the inverse of \(f(x) = \dfrac{2x + 1}{3}\)

Write \(y = \dfrac{2x+1}{3}\).
Multiply both sides by 3: \(3y = 2x + 1\)
Rearrange for \(x\): \(2x = 3y - 1 \Rightarrow x = \dfrac{3y - 1}{2}\)
Replace \(y\) with \(x\):

\[\boxed{f^{-1}(x) = \frac{3x-1}{2}}\]

8) Practice Questions — Composite and Inverse Functions

Try each one first. Then use the button to check the answer.

Question 1

Let \(f(x) = 4x - 3\) and \(g(x) = x + 2\).
Find \(fg(x)\) and \(gf(x)\), giving each in simplified form.

\(fg(x) = f(g(x)) = f(x+2) = 4(x+2) - 3 = 4x + 8 - 3 = 4x + 5\)
\(gf(x) = g(f(x)) = g(4x-3) = (4x-3) + 2 = 4x - 1\)

\[\boxed{fg(x) = 4x + 5, \qquad gf(x) = 4x - 1}\]

Question 2

Let \(f(x) = 3x + 1\) and \(g(x) = x^2\).
Find the value of \(fg(2)\).

First apply \(g\): \(g(2) = 2^2 = 4\)
Then apply \(f\): \(f(4) = 3(4) + 1 = 13\)

\[\boxed{fg(2) = 13}\]

Question 3

Find \(f^{-1}(x)\) where \(f(x) = 5x + 2\).

Write \(y = 5x + 2\).
Rearrange for \(x\): \(y - 2 = 5x \Rightarrow x = \dfrac{y-2}{5}\)
Replace \(y\) with \(x\):

\[\boxed{f^{-1}(x) = \frac{x-2}{5}}\]

Question 4

Find \(f^{-1}(x)\) where \(f(x) = \dfrac{x - 3}{4}\).

Write \(y = \dfrac{x-3}{4}\).
Multiply both sides by 4: \(4y = x - 3\)
Add 3: \(x = 4y + 3\)
Replace \(y\) with \(x\):

\[\boxed{f^{-1}(x) = 4x + 3}\]

Question 5 (More Difficult)

Let \(f(x) = 2x + 1\) and \(g(x) = x^2\).
Solve \(fg(x) = gf(x)\).

Find \(fg(x)\): \(fg(x) = f(x^2) = 2x^2 + 1\)
Find \(gf(x)\): \(gf(x) = g(2x+1) = (2x+1)^2 = 4x^2 + 4x + 1\)
Set them equal: \(2x^2 + 1 = 4x^2 + 4x + 1\)
Rearrange: \(0 = 2x^2 + 4x \Rightarrow 0 = 2x(x + 2)\)
Solve: \(x = 0\) or \(x = -2\)

\[\boxed{x = 0 \text{ or } x = -2}\]
